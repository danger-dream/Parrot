# Parrot WebUI

Vue 3 + Vite + TypeScript single-page console served by Parrot at `/ui/`. The built bundle lives in
`../src/webui/` and is committed; `src/tests/test_webui_bundle.py` fails when `webui/` sources change
without a rebuild (`pnpm build`).

## Layout of `src/`

| Path | Purpose |
|---|---|
| `api/client.ts` | `api.get/post/patch/put/del`, `ApiError`, `enc()` for path segments, `Schemas` (generated OpenAPI types) |
| `api/schema.d.ts` | Generated by `pnpm gen:api` from the backend. Never edit by hand. |
| `api/types.ts` | Short aliases for frequently used schemas and the WebSocket event map |
| `api/events.ts` | Live WebSocket (`onEvent(type, fn)` returns an unsubscribe function) |
| `api/operations.ts` | `waitOperation(op)` for 202 responses that return a long-running Operation |
| `composables/useResource.ts` | `useResource(path)` load + edit draft + save with If-Match; `runAction(fn, successText)` |
| `stores/ui.ts` | theme, toasts (`toast(title, tone, detail)`), inspector (`openInspector`) |
| `stores/dialogs.ts` | `confirmAction({...})`, `promptText({...})` — promise-based dialogs |
| `stores/catalog.ts` | `channelName(id)` for display names of routing channels |
| `links.ts` | Cross-page navigation: `openAccount`, `openChannel`, `openApiKey`, `openModel`, `openRequest`, `goLogs`, `goPage` |
| `nav.ts`, `pageRegistry.ts`, `router.ts` | Navigation entries, lazy page modules, routes |
| `components/ui/` | Design-system primitives (see below) |
| `components/StatsMini.vue`, `components/DetailSection.vue` | Shared building blocks for detail panels |
| `pages/<module>/` | One directory per module; the module owns everything inside it |
| `utils/format.ts` | Numbers, money (`usd(ticks)`), durations, Beijing-time clocks |
| `utils/errors.ts` | `errorTitle(err)`, `errorDetail(err)`, `fieldErrors(err)` — Chinese error text |

## Design language

macOS-like, quiet and dense. Use the CSS variables from `styles/tokens.css` only (no hard-coded colours
except brand glyphs): `--surface`, `--fill-*`, `--text`, `--text-2`, `--text-3`, `--border`,
`--hairline`, `--accent`, and the system colours `--blue --green --orange --red --purple --teal
--yellow --pink --indigo`. Both themes must look right — check light and dark.

- Numbers use `font-variant-numeric: tabular-nums`; identifiers (model ids, keys, URLs) use `.mono`.
- Status colours: green = healthy/success, orange = degraded/limited/cooldown, red = failed/invalid,
  neutral grey = disabled/unknown.
- Copy is plain Chinese a non-engineer understands: “已停用”, “额度用尽”, “测试连通性”. No raw enum
  values or English internals in the UI; map them to Chinese labels.
- Every list shows loading (Skeleton), empty (Empty) and error states.

## Page structure

```vue
<Page title="API 渠道" subtitle="一句话说明" width="wide">
  <template #actions><Btn variant="primary">新建渠道</Btn></template>
  <template #toolbar><SearchField v-model="q" /> <Segmented ... /></template>
  ...cards / lists...
</Page>
```

- `Page` gives consistent padding, max width and a sticky toolbar. It is a size container, so
  use `@container (max-width: …)` rules for responsive layouts; they react to the docked inspector.
- Grids of cards: `grid-template-columns: repeat(auto-fill, minmax(280px, 1fr))`; rows in a grid must
  stretch to equal height (`align-items: stretch`, cards `height: 100%`) — no ragged empty gaps.
- Tables: CSS grid rows like `pages/live/RequestRow.vue`; hide low-priority columns with container
  queries; below ~720px render rows as two-line cards.
- Mobile (<768px): nothing may overflow horizontally; touch targets ≥ 32px high; modals become
  bottom sheets automatically.

## Interaction patterns

- **Detail**: clicking a row opens the right-hand inspector (`openInspector(key, title, Component,
  props, subtitle)` or the `links.ts` helpers). Detail panels hold the actions for that object.
- **Create / edit**: `Modal` with `Field` + form controls; primary button in the footer. Disable the
  button while saving (`loading`), show server validation via `fieldErrors(err)`.
- **Settings**: `SettingsSection` + `useResource(path)`; edit `draft`, the section shows “保存/还原”
  when dirty; `save()` sends only changed fields with `If-Match`.
- **Destructive**: always `await confirmAction({ title, detail, danger: true })`; irreversible bulk
  deletes add `requireText`.
- **Secrets created by the server** (new API key, regenerated key): show once in a Modal with
  `CopyText` and the sentence “关闭后无法再次查看”.
- **Long operations** (HTTP 202 → Operation): `waitOperation(op, { onProgress })` with visible progress.
- **Feedback**: `runAction(() => api.post(...), '已刷新')` for one-off actions; toasts are short.
- **Optimistic toggles** are fine for switches; revert on error.

## Linking (required)

The console is one connected graph. Wherever an object appears, make it clickable:

| Object | Helper |
|---|---|
| OAuth account (`claude:x@y`) | `openAccount(accountId)` |
| Routing channel (`api:Name` or `oauth:…`) | `openChannel(channelId)` |
| API key | `openApiKey(keyId)` |
| Model id | `openModel(modelId)` |
| Request | `openRequest(id)` |
| Related requests | `goLogs({ model, channel, apiKey, status, from, to })` |
| Another page | `goPage('/updates')` |

Pages must also honour their deep-link query (e.g. `/oauth?account=ID` opens that account,
`/channels?channel=api:Name`, `/keys?key=Name`, `/models?model=id`).

## Live data

Use `onEvent('request.finished', …)` / `onEvent('runtime.snapshot', …)` where a page shows numbers
that change with traffic (unsubscribe in `onBeforeUnmount`). Otherwise refresh on focus/interval.

## Commands

```bash
export PATH=/root/.nvm/versions/node/v24.14.1/bin:$PATH
npx vue-tsc --noEmit          # typecheck (whole project)
pnpm gen:api                  # regenerate api/schema.d.ts (needs PARROT_PYTHON)
pnpm build                    # bundle into ../src/webui (integration only)
```
